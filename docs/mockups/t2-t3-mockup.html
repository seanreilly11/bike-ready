T2.4T2.5Crisp SVG sign in context · feedback panel with correct/wrong icon chip (meaning beyond colour)

You see this blue round sign at the start of a path. What does it mean for you as a cyclist?

Feedback panel

Correct

A blue circle is mandatory: this is a compulsory cycle path (verplicht fietspad). You must use it, and mopeds without an engine running may join.

Rule

Blue circle = obligation. Red circle = prohibition.

Tip

Blue means "you must" — not "you may".

The chip + check icon means a colour-blind user reads "correct" without relying on the green tint.
